# AviTok (АвиТок) — Объявления и Короткие Видео в одном приложении ⚡

**AviTok** — демонстрационный React/Vite-прототип доски объявлений и ленты коротких видео. Интерфейс локализован на русский язык и адаптирован для мобильных устройств. Это не готовый сервис: данные, объявления и переписки хранятся только в LocalStorage этого браузера, а ответы продавцов и некоторые действия имитируются.

---

## 🚀 Ключевые особенности

### 1. 🎬 Вертикальная видеолента (TikTok-style)
* **Лента видео:** Демонстрационные ролики объявлений с переключением, лайками и комментариями.
* **Действия с объявлением:** Кнопка **«Купить товар»** открывает карточку. «Поделиться» копирует ссылку с данными объявления, поэтому обычные демо-ссылки открываются и на другом устройстве. Для очень больших объявлений ссылка содержит только ID — тогда объявление должно уже храниться в браузере получателя.

### 2. 🔍 Умный каталог объявлений (Avito-style)
* **Полнотекстовый поиск:** Мгновенный поиск товаров по ключевым словам и описанию в реальном времени.
* **Категории-фильтры:** Быстрая фильтрация по категориям: *Все, Электроника, Транспорт, Недвижимость, Услуги, Одежда*.
* **Детальный просмотр:** Модальное окно с описанием, рейтингом продавца, количеством просмотров и кнопками связи.

### 3. 💬 Демонстрационные сообщения
* **Симуляция общения:** Наличие индикатора «печатает...» и автоматических ответов продавцов.
* **Быстрые ответы:** Кнопки мгновенных сообщений («Актуально?», «Какое состояние?», «Скидка будет?», «Где забрать?»).
* **Категорийные сценарии ответов:** Продавцы отвечают в зависимости от категории товара индивидуальными фразами.

### 4. ➕ Создание объявлений с авто-подбором медиа
* **Форма публикации:** Удобная форма для добавления названия, цены, категории и описания.
* **Автоматические пресеты:** Если ссылки на изображение или видео не указаны, приложение автоматически подберёт красивые и подходящие медиа-ресурсы под выбранную категорию!

### 5. ❤️ Избранное и Локальное хранилище
* Созданные объявления, избранное и переписки сохраняются в LocalStorage браузера. Это локальные демо-данные: они не синхронизируются между устройствами или пользователями и могут быть удалены настройками браузера.

### 6. 🛠️ Панель Бета-тестирования
* Интегрированное руководство и кнопка мгновенного сброса данных до исходного демо-состояния.

---

## 🛠️ Стек технологий

* **Frontend:** React (hooks, context, refs)
* **Сборщик:** Vite
* **Стилизация:** Tailwind CSS (v4) с плавными переходами и кастомными анимациями
* **Иконки:** Lucide React

## 💻 Быстрый запуск

### Установка зависимостей
```bash
npm install
```

### Запуск сервера разработки
```bash
npm run dev
```
После запуска приложение будет доступно по адресу `http://localhost:3000`.

### Сборка проекта для продакшена
```bash
npm run build
```
Команда компилирует оптимизированные статические ресурсы в директорию `dist/`.

### Проверки

```bash
npm test
npm run build
```

## 🚀 Размещение на Vercel (бесплатный адрес)

Проект — статическое Vite-приложение; отдельный `vercel.json` не нужен. Сборка — `npm run build`, папка результата — `dist`.

1. Опубликуйте проект в GitHub-репозитории (для автоматических обновлений Vercel нужен доступ к репозиторию).
2. Войдите или зарегистрируйтесь на [vercel.com](https://vercel.com/) через свой GitHub-аккаунт и разрешите Vercel доступ к этому репозиторию.
3. Нажмите **Add New → Project**, импортируйте AviTok и проверьте настройки: Framework Preset — **Vite**, Build Command — `npm run build`, Output Directory — `dist`, Root Directory — корень репозитория.
4. Нажмите **Deploy**. На бесплатном плане Hobby Vercel выдаст доступный адрес вида `имя-проекта.vercel.app`; его можно выбрать/изменить в настройках проекта в разделе Domains. Покупать собственный домен не требуется (бесплатный план действует на условиях Vercel).

В этом изменении проект только подготовлен к размещению: вход в аккаунт Vercel, импорт репозитория и публикация не выполнялись.
