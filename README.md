# AviTok (АвиТок) — Объявления и Короткие Видео в одном приложении ⚡

**AviTok** — это современное гибридное веб-приложение, объединяющее лучшие черты классической доски объявлений **Авито** и развлекательной бесконечной ленты коротких видео **TikTok**. Приложение полностью локализовано на русский язык, адаптивно для мобильных устройств и предлагает бесшовный интерактивный опыт.

---

## 🚀 Ключевые особенности

### 1. 🎬 Вертикальная видеолента (TikTok-style)
* **Бесконечный скроллинг видео:** Демонстрация товаров в динамичном формате коротких роликов.
* **Интерактивные взаимодействия:** Возможность поставить лайк (товар мгновенно добавляется в Избранное), открыть панель комментариев или поделиться ссылкой.
* **Прямая покупка:** Кнопка **«Купить товар»** прямо на видеоролике открывает детальную карточку объявления с возможностью написать или позвонить продавцу.

### 2. 🔍 Умный каталог объявлений (Avito-style)
* **Полнотекстовый поиск:** Мгновенный поиск товаров по ключевым словам и описанию в реальном времени.
* **Категории-фильтры:** Быстрая фильтрация по категориям: *Все, Электроника, Транспорт, Недвижимость, Услуги, Одежда*.
* **Детальный просмотр:** Модальное окно с описанием, рейтингом продавца, количеством просмотров и кнопками связи.

### 3. 💬 Умные интерактивные сообщения
* **Симуляция реального общения:** Наличие индикатора «печатает...» у продавцов.
* **Быстрые ответы:** Кнопки мгновенных сообщений («Актуально?», «Какое состояние?», «Скидка будет?», «Где забрать?»).
* **Категорийные сценарии ответов:** Продавцы отвечают в зависимости от категории товара индивидуальными фразами.

### 4. ➕ Создание объявлений с авто-подбором медиа
* **Форма публикации:** Удобная форма для добавления названия, цены, категории и описания.
* **Автоматические пресеты:** Если ссылки на изображение или видео не указаны, приложение автоматически подберёт красивые и подходящие медиа-ресурсы под выбранную категорию!

### 5. ❤️ Избранное и Локальное хранилище
* Все данные (созданные объявления, лайки/избранное, история переписок) надежно сохраняются на устройстве пользователя с помощью **LocalStorage** и не пропадают после перезагрузки страницы.

### 6. 🛠️ Панель Бета-тестирования
* Интегрированное руководство и кнопка мгновенного сброса данных до исходного демо-состояния.

---

## 🛠️ Стек технологий

* **Frontend:** React (hooks, context, refs)
* **Сборщик:** Vite
* **Стилизация:** Tailwind CSS (v4) с плавными переходами и кастомными анимациями
* **Иконки:** Lucide React

## 💻 Быстрый запуск

### Установка зависимостей
```bash
npm install
```

### Запуск сервера разработки
```bash
npm run dev
```
После запуска приложение будет доступно по адресу `http://localhost:3000`.

### Сборка проекта для продакшена
```bash
npm run build
```
Команда компилирует оптимизированные статические ресурсы в директорию `dist/`.
